# NewsCore AI — краткая концепция проекта

## Одна фраза
Веб-сервис, который собирает деловые новости РФ, очищает их от шума и доставляет персонализированный AI-дайджест.

## Проблема
Деловой человек тратит ~2,5 ч/день на чтение новостей: десятки источников, 80% — шум и дубли. Нет единой точки с релевантным контентом.

## Решение
NewsCore AI парсит 15+ авторитетных источников (РБК, Коммерсантъ, Forbes Russia и др.), прогоняет каждую статью через 7-шаговый AI-пайплайн и собирает персонализированный дайджест под роль пользователя.

**Ключевой принцип:** новости не генерируются — берутся с реальных сайтов, источник всегда сохраняется.

## Как это работает

```
Парсинг → Очистка → YandexGPT суммаризация → ruBERT классификация
→ NER-сущности → Importance scoring → Персонализированный дайджест
```

## MVP — что входит
- Веб-сервис (FastAPI + React/Next.js frontend)
- 5 категорий контента: аналитика, исследования, регуляторика, перспективы рынка, инвестиции
- Онбординг по роли (Инвестор / Владелец МСБ / Топ-менеджер / Аналитик)
- Email- и браузерные уведомления с готовым дайджестом
- Тарифы: Free / Standard 2 000 ₽ / Pro 3 000 ₽

## Экономика
- CAC ~1 500 ₽, LTV ~50 000 ₽ → LTV/CAC = **33x**
- Операционные расходы MVP: ~60 000 ₽/мес
- Цель 12 мес: 1 000 платящих пользователей → MRR 2,5 млн ₽

## Партнёры
- **Евразийское рейтинговое агентство** — якорный B2B-клиент + уникальный экспертный контент
- **ИТМО ФТМИ** — академическая поддержка
