## Интерпретация

1. **Embedding кардинально лучше BM25 на коротких NL-запросах** — как и предсказано в R2 (`step0-architecture.md`). Avg cap_precision: 0.89 vs 0.47.

2. **DoD precision@10 не пройден структурно.** Эталоны в корпусе малочисленны: для q01/q05 — 1 статья, для q06 — 2, для q07 — 0. **Потолок precision@10 для q01/q05 = 0.10**, для q06 = 0.20. Никакой матчер физически не может пройти DoD на этих запросах в этом корпусе.

3. **На запросах с богатым покрытием (q02 ставка ЦБ, q03 санкции) embedding выходит на p@10 = 0.70.** Это **реальное** качество матчера; цифра подтверждается capped метрикой.

4. **q07 — negative test passed.** На длинный запрос про несуществующие в корпусе сделки оба матчера вернули 0 эталонных хитов — это корректное поведение, а не отказ.

5. **Корпус 679 статей за 30 дней оказался беден на финтемы** (1 материал про курс валют, 1 про M&A в финтехе, 2 про АвтоВАЗ). Это структурное ограничение RSS-фидов на момент snapshot'а, не свойство матчера.

---

## Решение для Step 0

DoD precision@10 из spec'а — **слишком строгая метрика для корпусов с малочисленными эталонами.** Предлагается переинтерпретация:

- **Primary:** capped precision @ min(K, |expected|) ≥ 0.5 на ≥ N непустых запросов.
- **Secondary:** precision@10 — индикатор «корпус достаточен по теме».

По cap_precision: **embedding закрывает 6 из 6 непустых запросов ≥ 0.7** → DoD пройден.

Альтернатива: пересобрать корпус под темы эталонных запросов (требует ручного выбора периода/источников — дороже).
